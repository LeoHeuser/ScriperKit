# ScriperKit

ScriperKit is a system that generates screenshots of apps for iPhones and iPads. It creates screenshots based on code with normalized native UI elements, such as the status bar with connectivity and battery information.

This improves the quality and fidelity of screenshots for the App Store. It also reduces the effort required to create new screenshots in all languages the app is available in.

This is a package that can be easily embedded into Apple platform apps to automatically generate screenshots.
